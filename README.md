## 🌟 Overview

The **Hotel Lobby AI Video Generator** is an online vertical video tool fine-tuned for generating viral short-form rap music performance clips in the iconic **A COLORS SHOW** aesthetic. 

Instead of dealing with complex local ComfyUI installations, missing models, or GPU memory constraints, creators can upload a single static portrait and output vertical 9:16 video clips with natural head movement, body cadence, and hanging microphone interactions.

## 🛠️ How It Works

1. **Upload**: Select a high-resolution front-facing portrait (human, anime character, or pet).
2. **Select Mode**: Choose between a 6-second hook loop or a 15-second full verse.
3. **Generate**: The Wan 3.0 diffusion model preserves facial identity while generating realistic performance motion.
4. **Export**: Download your 9:16 MP4 file and add trending audio in CapCut or Premiere.
